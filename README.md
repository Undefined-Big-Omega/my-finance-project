# Finance service (my-finance-project)

Консольное приложение для учета финансов

## Установка и запуск

### Способ 1: Maven (рекомендуется)

```bash
# Компиляция проекта
mvn clean compile

# Запуск приложения
mvn exec:java

# Сборка JAR-файла
mvn clean package

# Запуск JAR-файла
java -jar target/personal-finance-manager-1.0.0.jar
```

### Способ 2: Javac (быстрый старт)

```bash
# Компиляция
javac -d out -encoding UTF-8 src/finance/**/*.java src/finance/*.java

# Запуск
java -cp out finance.Main
```

### Альтернативный способ (одной командой)

```bash
javac -d out -encoding UTF-8 src/finance/**/*.java src/finance/*.java && java -cp out finance.Main
```

## Как пользоваться сервисом

### Требования к безопасности паролей

Для обеспечения безопасности аккаунтов установлены следующие требования к паролям:

- **Минимальная длина**: 5 символов
- **Обязательное наличие**:
    - Минимум 1 заглавная буква (A-Z)
    - Минимум 1 строчная буква (a-z)
    - Минимум 1 цифра (0-9)
    - Минимум 1 специальный символ (!@#$%^&*()_+-=[]{}; и т.д.)
- **Допустимые символы**: только английские буквы, цифры и специальные символы
- **Примеры валидных паролей**: `Pass1!`, `MyP@ssw0rd`, `Secure#123`


### Первый запуск

При первом запуске приложения появится меню авторизации:

```
Система управления личными финансами
Необходима авторизация

 1) Войти
 2) Зарегистрироваться
 9) Справка
 0) Выход
 Ваш выбор:
```

Выберите:
- `1` для входа в существующий аккаунт
- `2` для регистрации нового пользователя
- `9` для просмотра справки с описанием команд
- `0` для выхода из приложения

**Примечание:** В меню входа и регистрации можно также ввести `0` для возврата в главное меню авторизации.

### Главное меню

После авторизации вы увидите главное меню:

```
--- Главное меню (Пользователь: username) ---
Баланс: 0.00 руб.

1) Добавить доход
2) Добавить расход
3) Установить/изменить бюджет
4) Посмотреть статистику
5) Посмотреть бюджеты
6) Посмотреть последние транзакции
7) Перевести средства другому пользователю
8) Управление категориями
9) Сменить пользователя
10) Справка
0) Выход
Введите команду:
```

**Подсказка:** Введите `10` в главном меню для просмотра подробной справки по всем командам.

## Поддерживаемые команды

### 1. Добавить доход

Добавляет доход в указанную категорию.

**Пример использования:**
```
>>> Добавление дохода
Категория (например, Зарплата, Бонус): Зарплата
Сумма: 50000
Описание (необязательно): Месячная зарплата
Доход добавлен успешно!
Текущий баланс: 50000.00 руб.
```

### 2. Добавить расход

Добавляет расход в указанную категорию. Если для категории установлен бюджет, он автоматически обновляется.

**Пример использования:**
```
>>> Добавление расхода
Категория (например, Еда, Развлечения, Коммунальные услуги): Еда
Сумма: 3000
Описание (необязательно): Продукты
Расход добавлен успешно!
Текущий баланс: 47000.00 руб.
```

### 3. Установить/изменить бюджет

Устанавливает лимит бюджета для категории расходов.

**Пример использования:**
```
>>> Установка/изменение бюджета
Категория расходов: Еда
Лимит бюджета: 10000
Бюджет установлен успешно!
```

### 4. Посмотреть статистику

Отображает подробную статистику по доходам и расходам.

**Пример вывода:**
```
--- Статистика ---

Общий доход: 60000.00 руб.

Доходы по категориям:
  Зарплата: 50000.00 руб.
  Бонус: 10000.00 руб.

Общие расходы: 8300.00 руб.

Расходы по категориям:
  Еда: 5000.00 руб.
  Развлечения: 3000.00 руб.
  Коммунальные услуги: 300.00 руб.

Текущий баланс: 51700.00 руб.

Посчитать сумму по нескольким категориям? (y/n):
```

**Подсчет по выбранным категориям:**
Если выберете `y`, можно указать категории через запятую:
```
Введите названия категорий через запятую:
Еда, Развлечения

Общая сумма по выбранным категориям: 8000.00 руб.
```

Если категория не найдена, система выведет предупреждение:
```
Следующие категории не найдены: НесуществующаяКатегория
```

### 5. Посмотреть бюджеты

Показывает состояние всех установленных бюджетов.

**Пример вывода:**
```
--- Бюджеты по категориям ---

Еда:
  Лимит: 10000.00 руб.
  Потрачено: 5000.00 руб.
  Осталось: 5000.00 руб.
  Использовано: 50.0%

Развлечения:
  Лимит: 5000.00 руб.
  Потрачено: 6000.00 руб.
  Осталось: -1000.00 руб.
  СТАТУС: ПРЕВЫШЕН (на 1000.00 руб.)
```

### 6. Посмотреть последние транзакции

Выводит список последних транзакций.

**Пример использования:**
```
--- Последние транзакции ---
Сколько последних транзакций показать? (по умолчанию 25): 5

07.11.2025 - Доход - Зарплата
  Сумма: 50000.00 руб.
  Описание: Месячная зарплата

07.11.2025 - Расход - Еда
  Сумма: 3000.00 руб.
  Описание: Продукты
```

### 7. Перевести средства другому пользователю

Переводит деньги другому зарегистрированному пользователю.

**Пример использования:**
```
>>> Перевод средств
Логин получателя: ivan
Сумма перевода: 5000
Описание (необязательно): Долг за обед
Перевод выполнен успешно!
Ваш новый баланс: 45000.00 руб.
```

У отправителя фиксируется расход, у получателя - доход.

### 8. Управление категориями

Позволяет просматривать, переименовывать и удалять категории.

**Пример использования:**
```
>>> Управление категориями

1) Просмотреть все категории
2) Переименовать категорию
3) Удалить категорию
0) Назад в главное меню
Ваш выбор: 1

>>> Список всех категорий

Зарплата:
  - Тип: Доход
    Всего транзакций: 60000.00 руб.

Еда:
  - Тип: Расход
    Бюджет: 10000.00 руб.
    Всего транзакций: 5000.00 руб.
```

**Переименование категории:**
- Обновляет все существующие транзакции
- Сохраняет бюджет для категорий расходов
- Нельзя переименовать в уже существующее имя

**Удаление категории:**
- Невозможно удалить категорию с существующими транзакциями
- При удалении категории расходов автоматически удаляется связанный бюджет
- Требует подтверждения действия

### 9. Сменить пользователя

Выход из текущего аккаунта с сохранением данных и вход в другой аккаунт.

### 0. Выход

Сохраняет все данные в файлы и завершает работу приложения.

## Система уведомлений

Приложение автоматически отслеживает состояние ваших финансов и выводит предупреждения:

### Превышение бюджета
```
------------------------------------------------------------
Превышен бюджет категории 'Еда'! Потрачено 6000.00 руб. из 5000.00 руб. (перерасход: 1000.00 руб.)
------------------------------------------------------------
```

### Приближение к лимиту (50% и более)
```
------------------------------------------------------------
Бюджет категории 'Развлечения' почти исчерпан! Использовано 50.0% (2500.00 руб. из 5000.00 руб.)
------------------------------------------------------------
```

### Отрицательный баланс
```
------------------------------------------------------------
Отрицательный баланс! Текущий баланс: -500.00 руб.
------------------------------------------------------------
```

### Расходы превышают доходы
```
------------------------------------------------------------
Расходы превышают доходы! Доходы: 50000.00 руб., Расходы: 55000.00 руб.
------------------------------------------------------------
```

## Контроль качества кода

### Checkstyle

Проект использует Checkstyle для контроля качества и стилистики кода.

```bash
# Проверка кода через Maven
mvn checkstyle:check

# Генерация отчета Checkstyle
mvn checkstyle:checkstyle

# Просмотр отчета (генерируется в target/site/checkstyle.html)
open target/site/checkstyle.html
```

### Правила Checkstyle

Конфигурация включает проверки:
- Именование классов, методов, переменных
- Корректность импортов
- Размер файлов и методов (до 500 и 150 строк соответственно)
- Форматирование и отступы
- Порядок модификаторов
- Блоки кода и скобки
- Цикломатическая сложность (до 10)
- Javadoc для публичных методов и классов

## Тестирование

### Запуск тестов через Maven

```bash
# Компиляция и запуск всех тестов
mvn test

# Запуск тестов с подробным выводом
mvn test -X
```

### Запуск тестов через Javac

```bash
# Компиляция исходного кода и тестов
find src -name "*.java" -exec javac -d target/classes -cp src {} +
javac -cp target/classes -d target/classes test/*.java

# Запуск тестов
java -cp target/classes MainTest
java -cp target/classes RequirementsCheckTest
```
